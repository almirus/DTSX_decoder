# DTS:X Object Viewer

Локальное графическое приложение для содержимого каталога, созданного
`dtsx-decode --objects-output-dir`.

Запуск из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\object-viewer\start.ps1
```

В открывшемся окне нажмите **Открыть папку** и выберите каталог с парами
`object_*.wav` / `object_*.coordinates.jsonl`.

- все mono WAV воспроизводятся синхронно;
- большие WAV/RF64 не разворачиваются целиком через `decodeAudioData`, а
  воспроизводятся потоково через media source; большие JSONL также читаются
  порциями, поэтому полнометражные экспорты не требуют десятков гигабайт RAM;
- при наличии `bed.json` связанный многоканальный `bed.wav` запускается
  синхронно с объектами, а его каналы появляются отдельным блоком под ними;
- bed сводится в стерео явной матрицей: `FL`/`FR` без ослабления, `FC`,
  surround и height с `-3 dB`, `LFE` по центру с `-6 dB`; полностью пустые
  каналы помечаются и не включаются;
- после суммы bed и объектов стоит выходной limiter, защищающий стереовыход от
  редких межканальных пиков выше `0 dBFS`;
- каждый mono stem проходит через отдельный equal-power stereo panner:
  pan берётся из декартова смещения по оси X, поэтому учитывает одновременно
  азимут, elevation и distance; верхняя/нижняя точка и центр сцены звучат по
  центру, левое/правое смещение уходит в соответствующий канал;
- громкость каждого объекта следует за временными интервалами sidecar и
  применяет итоговый `metadataGainLinear` (с резервным чтением
  `metadataGainQ23`/`metadataGainDb`), рассчитанный декодером из
  `objectGainPresent`, `objectGainCode`, `objectGainExponent`, point gain и
  `presentationGainCode`; в настройках объектов metadata gain можно отключить,
  тогда все mono stems воспроизводятся с коэффициентом `1.0`;
- каждый объект можно отдельно включить или выключить;
- общий переключатель объектов включает/выключает все дочерние переключатели и
  остаётся включённым, пока активен хотя бы один объект;
- положение берётся только из записей с `coordinateStatus: "decoded"`;
- новые sidecar также учитывают `renderable` и `audioActive`: исключённые
  native renderer'ом или молчащие в текущем PCM-блоке объекты скрываются;
- если все decoded-координаты stem совпадают, объект считается статичным:
  фиксированная точка отображается даже при `renderable: false`, но только в
  аудиоактивных временных интервалах;
- интервалы sidecar сопоставляются с воспроизведением в целых `ptsSamples`,
  поэтому между соседними 512-sample блоками нет floating-point мерцания;
- если в DTS:X кадре нет новой decoded-строки, последняя известная позиция и
  состояния `renderable`/`audioActive` сохраняются до следующего обновления:
  отсутствие metadata update не считается выключением объекта;
- число внутри цветного маркера - настоящий `objectId` из sidecar;
- пунктирная сфера показывает нормативный радиус `1.0`; объекты с меньшим
  `distance` находятся внутри неё, с большим — снаружи;
- маркеры масштабируются по глубине сцены: ближние к камере отображаются
  крупнее, дальние — меньше;
- опциональный размер из metadata нормализует максимальное из `widthDeg` и
  `heightDeg` по диапазону `0…360°` в ограниченный масштаб маркера `1×…2×`;
  изменение extent плавно интерполируется между временными состояниями, а
  настройка по умолчанию выключена;
- цветные маркеры имеют лёгкое объёмное затенение, а движущиеся объекты
  оставляют короткий полупрозрачный хвост; у статичных объектов хвоста нет;
- в разворачиваемых настройках объектов можно отключить хвост, изменить его
  длину, отключить перспективное масштабирование маркеров и скрыть пунктирные
  линии от центра сцены к объектам;
- в центре сцены отображается low-poly диван Kenney `loungeSofa`
  ([Furniture Kit](https://kenney.nl/assets/furniture-kit), CC0), обращённый
  лицом к фронту (`FC` / +Z); его можно скрыть переключателем «Диван в центре»;
- каналы из `bed.json`, включая height, подписаны в своих позициях на сцене;
  недостающие каналы дополняются постоянной опорной схемой `7.1.4`, поэтому
  названия видны даже без bed или при его отключении; буквы названий
  масштабируются по глубине сцены вместе с маркерами объектов и подчиняются
  переключателю «Масштаб по глубине»; все названия можно скрыть в настройках
  объектов;
- ЛКМ вращает сцену, колесо меняет масштаб, двойной щелчок сбрасывает камеру;
- пробел переключает воспроизведение и паузу.

Приложение работает локально, не загружает аудио или координаты в сеть и не
требует установки npm/Python-пакетов.
